
# Sales & Revenue Dashboard

**Role:** Business Analyst | Personal Project  
**Focus:** SQL • Excel • Power BI • Data Visualization • Business Insights • Dashboard UX

## Business Problem

A retail business needs a clear view of revenue, profit, product performance and regional performance so management can identify trends and business gaps.

## Objective

Turn transaction-level sales data into a clean analytical model and an executive dashboard that answers:

**What happened? Where? Which products/categories drive performance? What should management investigate next?**

## Deliverables

- Retail sales dataset
- Data-quality checks
- SQL analysis
- Excel PivotTable/KPI plan
- Power BI dashboard specification
- Dashboard UX design system
- Confluence documentation structure
- Analytical findings template
- Stakeholder presentation structure

## Tools

**SQL | MS Excel | Power BI | MS Word | Confluence | MS PowerPoint**

> Synthetic data is used for portfolio purposes.
